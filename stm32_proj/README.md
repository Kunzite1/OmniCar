# STM32F407VET6 固件工程（暂时废弃）

> **状态：暂时废弃。** 当前固件开发已经迁移到 [STM32F103RCT6 工程](../stm32f103rct6_proj/README.md)，请不要在本目录继续新增功能或调整 CubeMX 配置，除非明确决定恢复 F407 硬件方案。

本目录保留迁移前的 STM32F407VET6 固件，用于追溯原有五层架构、外设驱动、CAN 协议和迁移差异。它不是当前构建、烧录或功能开发入口。

## 保留用途

- 对照 F407 与 F103 的 HAL、时钟、FreeRTOS port 和引脚差异。
- 在迁移尚未完成全部板上验证前，保留一份可追溯的旧实现。
- 必要时查阅旧转接板的[引脚分配](../docs/引脚分配.md)。
